# Exposure Therapy for Phobias in Virtual Environments with Haptic Feedback
This project introduces an immersive therapeutic system designed to treat specific phobias using virtual reality (VR) combined with haptic feedback. The system allows patients to confront their fears in a controlled and progressive way through realistic simulations presented via a Meta Quest 3 headset and enhanced by the Teslasuit, a full-body haptic suit capable of delivering precise tactile sensations, motion tracking, and biometric monitoring.

Patients are exposed to scenarios that trigger their phobias, such as spider or heights, within a safe virtual environment. The physical sensations provided by the Teslasuit help deepen immersion and reinforce the realism of the experience, increasing the emotional engagement necessary for effective therapy. A specialist supervises and manually adjusts the intensity of both the virtual stimuli and haptic responses based on the patient's tolerance and progression, allowing for a tailored desensitization process.

The virtual environments are developed using Unity, which provides the flexibility and performance needed to construct interactive 3D scenes. The logic and interaction mechanisms are implemented in C#, ensuring smooth communication between the simulation and the Teslasuit. Teslasuit’s Control Center and Studio applications are employed to configure and monitor the suit, manage session parameters, and collect physiological data like heart rate.
